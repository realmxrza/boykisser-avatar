## Download

1. Open the [latest release](https://github.com/realmxrza/boykisser-avatar/releases/latest).
2. Download `Boykisser-Avatar-Setup-1.0.0.exe`.
3. Run the installer. Windows may show "Windows protected your PC" because the app is not code-signed. Select **More info** and then **Run anyway**.
4. Launch **Boykisser Avatar** from the desktop or Start menu.

## Controls

- `Ctrl+Shift+M` — mute/unmute the microphone
- `Ctrl+Shift+B` — drag boykisser

## Uninstall

Open **Settings → Apps → Installed apps → Boykisser Avatar → Uninstall**, or run `Uninstall.exe` from the install folder.
